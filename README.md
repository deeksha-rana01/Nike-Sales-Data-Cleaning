# Nike Sales Data Cleaning

## Overview
This project focuses on cleaning and preprocessing an uncleaned Nike sales dataset using Python.

## Key Operations
- Missing value identification and handling
- Data type conversion
- Outlier detection using the IQR method
- Invalid value treatment
- Before-and-after data comparison
- Cleaned dataset export

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Conclusion
The project demonstrates practical data cleaning techniques to improve dataset quality and prepare data for further analysis.
